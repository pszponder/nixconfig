# Host-name ideas

A list of names for future hosts, VMs, services, and experiments. Hostnames should be lowercase and use hyphens only when needed.

## Magic: The Gathering planes

These are planes in the *Magic: The Gathering* multiverse. Color combinations and other regional labels are intentionally excluded.

### Familiar and versatile

- **Dominaria** — the classic, central setting; a good name for a primary workstation or all-purpose host.
- **Ravnica** — guilds, infrastructure, and dense city life; a natural fit for a server or home-lab host.
- **Zendikar** — exploration and discovery; a good name for a test machine or experimental environment.
- **Innistrad** — gothic horror; suited to a security, monitoring, or spooky-project host.
- **Theros** — mythology and heroic quests; a fitting name for a personal or flagship machine.

### Distinctive environments

- **Mirrodin** — metal, artifacts, and machinery; a strong name for hardware or build infrastructure.
- **Kamigawa** — tradition blended with technology; a good fit for a hybrid or development host.
- **Kaladesh** — invention and energy; suited to a creative or maker-focused machine.
- **Amonkhet** — desert trials and ancient monuments; a memorable name for a resilient or archival host.
- **Ixalan** — exploration, jungles, and lost cities; a good name for a travel or discovery project.
- **Kaldheim** — cold, rugged, and saga-driven; fitting for a durable backup or storage host.
- **New Capenna** — neon noir and organized factions; a stylish name for a network-facing service.
- **Lorwyn** — idyllic and storybook-like; a friendly name for a lightweight or personal host.
- **Eldraine** — fairy tales, castles, and adventure; a good name for a creative project host.
- **Tarkir** — clans, dragons, and conflict; fitting for a powerful build or compute host.
- **Strixhaven** — magical scholarship; a natural name for a development or learning machine.
- **Arcavios** — the plane containing Strixhaven; a broader alternative for an education-focused host.
- **Phyrexia** — biomechanical industry and relentless systems; suited to an automation or infrastructure host.

## Naming notes

- Use the place name directly when it is short and readable, such as `ravnica`, `tarkir`, `asgard`, or `bree`.
- Use a shortened or adapted form when punctuation or spaces would make the hostname awkward, such as `middle-earth` or `minas-tirith`.
- Prefer locations over people, gods, heroes, villains, creatures, color identities, guilds, clans, sets, or characters.
